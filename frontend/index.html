Help & Documentation

Quick Start

  • Configure Bay Mapping: Go to System Administration tab (Tab 4) and use "Auto-Detect" or manually map bays
  • Wipe a Drive: Enable "Sanitize Mode" toggle, select drive(s) in Active Workbench, click "Configure Sanitization"
  • View Certificates: Check the Compliance Audit Vault tab (Tab 3) for completed wipes
  • Batch Intake: Use the Batch Intake Triage tab (Tab 2) to assess all connected drives before wiping

  • - Step-by-step workflow for health checking and erasing drives

  • - System Administration panel features

  • - Installation, releases, validation, and rollback

Common Tasks

  • Check Service Status: sudo systemctl status drive-eraser
  • View Logs: sudo journalctl -u drive-eraser -f
  • Restart Service: sudo systemctl restart drive-eraser
